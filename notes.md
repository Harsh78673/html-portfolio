# HTML Portfolio Website Project (Multiple Pages)
**Assignment:** Create a personal portfolio website using only HTML, without CSS or JavaScript.

**Objective:** Learn HTML page structure, hyperlinks, navigation, images, lists, tables, and forms by creating a multi-page website.

#### Semantic HTML tags:  
    Clearly describe their meaning and purpose to both browsers and developers. For eg: ye wo tags hote hai jinke name se hi unke use ka pata chal jata hai.
