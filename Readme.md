# HTML Portfolio Website

A personal portfolio website built using HTML5 as part of my Full Stack Web Development learning journey.

This project focuses on learning HTML fundamentals by creating a multi-page website with navigation links, images, tables, lists, forms, and embedded video content.

## 📌 About the Project

This portfolio introduces me, showcases my skills and projects, shares information about my background, and provides contact details.

It is a beginner-level project created to practice HTML structure and understand how multiple web pages connect through navigation links.

## ✨ Features

* **Home Page:** Introduction and overview of the portfolio.
* **About Page:** Personal introduction, education, hobbies, career objective, and strengths.
* **Skills Page:** Technical skills, soft skills, and language information.
* **Projects Page:** Project descriptions, technologies, and future project ideas.
* **Contact Page:** Contact information, social links, a basic HTML form, and an embedded Google Map.
* **Multi-Page Navigation:** Navigation links between all portfolio pages.
* **Images and Video:** Displays images and embedded video content.
* **Semantic HTML:** Uses elements such as `header`, `nav`, `section`, and `footer` to organize content.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code to preview the website locally.
